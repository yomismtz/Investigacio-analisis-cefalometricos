Preguntas frecuentes

Lo esencial antes de empezar.

¿Los valores “normales” son universales?

No. Yornis distingue referencias históricas, referencias de muestra y valores por edad/sexo cuando la evidencia es geométricamente compatible. Si no existe una referencia válida, no interpola una.

¿Necesita internet para analizar radiografías?

No. La aplicación de escritorio funciona localmente. Internet sólo es necesario para descargar nuevas versiones.

¿Yornis es gratis?

Sí. La descarga no requiere suscripción y la versión estable se distribuye desde GitHub Releases.

¿Es un dispositivo médico?

No. Yornis se identifica como herramienta educativa y de investigación. La validación de software no sustituye la validación clínica externa.
