Un flujo completo, sin nube obligatoria

Del trazado a la base de datos, sin perder el control del método.

Yornis fue diseñado para trabajo educativo y de investigación. Separa la geometría de las referencias clínicas, conserva auditoría de resultados y evita convertir una media histórica en un diagnóstico automático.

Funciones

Una app para el caso individual y para la investigación.

La interfaz mantiene el concepto de aves de Yornis: precisión, perspectiva y movimiento, con temas inspirados en distintas especies.

01

Trazado guiado

Landmarks mínimos según las variables seleccionadas, lupa, arrastre, zoom, calibración y control geométrico.

02

Modo Investigación

Protocolos versionados, criterios de inclusión/exclusión, aleatorización reproducible, hasta 1000 casos y estados auditables.

03

Exportación científica

CSV, sintaxis SPSS, JSON pseudonimizado, Excel/PDF y respaldo consistente de SQLite.

04

Referencias dentro de la app

Botón de ayuda y F1 con tablas nativas, texto nítido HiDPI y lectura menor / dentro / mayor a la referencia.

05

Cervical y crecimiento

CVM C2–C4, lordosis C1–C7, alineación cervical y análisis cráneo-cervical con interpretación prudente.

06

Privacidad local

Radiografías y base de datos permanecen en el equipo. Yornis no exige cuenta, servidor remoto ni subida automática de pacientes.

Transparencia

Auditoría clínica y técnica visible.

El objetivo no es “hacer que el build quede verde”, sino documentar qué se comprobó y qué sigue necesitando validación externa.

Geometría y regresión

La suite recorre todas las mediciones automáticas con geometría sintética no degenerada y pruebas específicas de Wits, CVM, HP y resultados cervicales.

Datos y exportación

Pruebas para historial de outcomes, SQLite/WAL, backups/restauración, privacidad JSON y sintaxis SPSS.

Windows y HiDPI

PerMonitorV2, Segoe UI, arranque en frío, instalador y checksums SHA-256 forman parte de la cadena final.

Límite explícito

Pasar pruebas de software no equivale a validación clínica externa. Yornis debe compararse contra trazados de referencia y reproducibilidad intra/interobservador para estudios de validación.

Preguntas frecuentes

Lo esencial antes de empezar.

¿Yornis es gratis?

Sí. La descarga no requiere suscripción. El sitio se aloja en GitHub Pages y la versión estable se distribuye desde GitHub Releases.

¿Necesita internet para analizar radiografías?

No. La aplicación de escritorio funciona localmente. Internet sólo es necesario para descargar nuevas versiones desde esta web.

¿Los valores “normales” son universales?

No. Yornis distingue referencias históricas de interpretación clínica. Edad, sexo, población, biotipo y técnica radiográfica pueden modificar la lectura.

¿Es un dispositivo médico?

No. Yornis se identifica como herramienta educativa y de investigación. La validación de software no sustituye validación clínica externa.
