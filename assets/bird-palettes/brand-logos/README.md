# Logotipos YomDental / YomCeph por paleta

Sube aquí el logotipo de YomDental o YomCeph que corresponda al ave de cada paleta.

- Formato recomendado: `.png` con fondo transparente.
- Nombra cada archivo con el ave/paleta y la marca, por ejemplo: `Agaporni_YomDental.png` o `Agaporni_YomCeph.png`.
- Puedes incluir uno o ambos logotipos para cada paleta, según corresponda.
