# Sonidos de aves por paleta

Sube aquí el sonido del ave que corresponde a cada paleta de color.

- Formatos recomendados: `.wav` (preferido para integración offline) o `.mp3`.
- Usa el nombre de la paleta/ave de forma consistente, por ejemplo: `Agaporni.wav`, `Tucan.wav`, `Colibri.wav`.
- Un archivo por paleta. No sobrescribas otros sonidos.
