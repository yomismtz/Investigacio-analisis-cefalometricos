# Iconos de aves por paleta

Sube aquí la imagen del icono del ave correspondiente a cada paleta.

- Formato recomendado: `.png` con fondo transparente.
- Usa el mismo nombre de la paleta/ave que en la carpeta de sonidos, por ejemplo: `Agaporni.png`, `Tucan.png`, `Colibri.png`.
- Un icono por paleta.
